# Hola, soy Gerson Lujan 👋

Desarrollador **Full-Stack & Mobile** enfocado en construir aplicaciones web, móviles y sistemas de negocio rápidos, mantenibles y con excelente experiencia de usuario. Me importa tanto el diseño visual como la solidez técnica: arquitectura limpia, QA estricto y cero regresiones.

---

### Lo que construyo
- 💻 **Frontend Moderno:** Aplicaciones web reactivas y escalables con **React**, **Angular** y **Vite**.
- ⚡ **Backend & Datos:** Autenticación, bases de datos PostgreSQL y APIs en tiempo real con **Supabase**.
- 📱 **Mobile & Sistemas de Negocio:** Aplicaciones **Android** y plataformas de gestión comercial (POS / ventas).
- 🧠 **Fundamentos & Algoritmos:** Análisis de complejidad y resolución de problemas en **Python**.
