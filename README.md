# Hola, soy Gerson Lujan 👋

Desarrollador **Full-Stack & Mobile** enfocado en construir aplicaciones web, móviles y sistemas de negocio sólidos, rápidos y fáciles de mantener. Combino desarrollo moderno en **TypeScript / React / Angular** con backends en **.NET, Supabase, Python y Java**, cuidando siempre la arquitectura, el testing y cero regresiones.

---

### Lo que construyo
- 💻 **Frontend Moderno:** Aplicaciones web reactivas con **React**, **Angular**, **Vite** y **Tailwind CSS**.
- ⚙️ **Backend & Datos:** APIs y bases de datos con **Supabase (PostgreSQL)**, **ASP.NET Core / C#**, **SQL Server**, **FastAPI** y **Java**.
- 📱 **Mobile & Sistemas de Negocio:** Apps **Android (Kotlin)** y plataformas comerciales (POS, inventario y finanzas).
- 🤖 **Visión por Computadora, Robótica & Algoritmos:** Proyectos con **Python**, **OpenCV**, **YOLO**, **MediaPipe** y **Arduino/C++**.
